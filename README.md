 # Family Expense Tracker 🏠💸

A simple, lightweight command-line Python application designed to help families track daily expenses, manage categories, and monitor monthly budgets.

## Features
- **JSON Data Persistence:** Automatically saves your expenses and budget locally so you never lose data.
- **Budget Monitoring:** Set a monthly budget and get alerts if your family goes over budget.
- **Category Breakdown:** View spending grouped by categories (Food, Utilities, Rent, Healthcare, etc.).
- **Family Member Tagging:** Easily include who made the expense in the description.

## Requirements
- Python 3.x installed on your machine.

## How to Run
1. Open your terminal or command prompt inside the project folder.
2. Run the following command:
	```bash
	python tracker.py
	```
